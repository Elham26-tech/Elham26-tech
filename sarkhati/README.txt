سرخطی‌زن
=========

اجرا: روی فایل  sarkhati.exe  دوبار کلیک کنید.

همین. هیچ چیزی نصب نمی‌شود — نه Node، نه هیچ برنامهٔ دیگری.
نسخهٔ Node داخل خودِ همین فایل است.

چه اتفاقی می‌افتد:
  ۱. یک پنجرهٔ مشکی باز می‌ماند (نبندیدش، موتور برنامه همان است)
  ۲. صفحهٔ کنترل خودش در مرورگر باز می‌شود
  ۳. اگر باز نشد، این نشانی را در مرورگر بزنید:  http://127.0.0.1:9117

برای بستن برنامه، همان پنجرهٔ مشکی را ببندید.

اگر ویندوز اخطار SmartScreen داد:
  More info  →  Run anyway
(چون فایل امضای دیجیتال ندارد؛ طبیعی است.)

تنظیمات کنار خود فایل، در پوشهٔ  sarkhati-data  ذخیره می‌شود.

پیش‌نیاز: فقط کروم یا اِج که روی ویندوز دارید — برای باز کردن ایزی‌تریدر.
