# سیگنال پرایس‌اکشن — EUR/USD، طلا، GBP/JPY

این وب‌اپ روی سرور اجرا می‌شود و کارهای زیر را انجام می‌دهد:

- کندل‌های زنده‌ی سه نماد را از **TradingView** می‌خواند: یورو/دلار، طلا (XAU/USD) و پوند/ین.
- بازار را به روش دوره‌ی پرایس‌اکشن **سعید خاکستر** تحلیل می‌کند.
- با کمک **هوش مصنوعی Claude** سیگنال خرید، فروش یا «صبر» می‌دهد، همراه با نقطه‌ی ورود، حد ضرر، تارگت‌ها و استدلال.

> ⚠️ این برنامه ابزار کمک‌تحلیل است، نه توصیه‌ی مالی. هر سیگنال را خودتان بررسی کنید و همیشه حد ضرر بگذارید.

## چطور کار می‌کند

1. **داده**
   - برنامه به همان سوکت داده‌ای وصل می‌شود که نمودارهای tradingview.com از آن می‌خوانند.
   - کندل‌ها را در پنج تایم‌فریم نگه می‌دارد: ۱۵ دقیقه، ۱ ساعته، ۴ ساعته، روزانه و هفتگی.
   - این مسیر API رسمی نیست. اگر TradingView آن را تغییر دهد، فقط فایل `lib/tradingview.js` باید اصلاح شود.
2. **خوانش بازار به روش دوره** (`lib/analysis.js`)
   - ATR با پریودهای دوره: ۱ ساعته ۲۴، ۴ ساعته ۳۰، روزانه ۲۲، هفتگی ۵۲. توان حرکتی (TH) برابر ۰٫۶۶٪ قیمت است.
   - نقش تایم‌ها: ساختار = روزانه، پترن (گام) = ۴ ساعته، تریگر = ۱ ساعته، تلورانس = ۱۵ دقیقه، بستر = هفتگی.
   - کلاس کندل‌ها: اسپینینگ، استاندارد، لانگ‌بار، اسپایک و کندل مستر.
   - پیوت‌ها: حرکت سه‌کندلی یا ۲٫۵ ATR، سپس برگشت ۰٫۸ ATR.
   - زون هر سطح از نوک شادو تا بدنه است.
   - ارزش سطح بر اساس این عوامل حساب می‌شود: تایم، تعداد برخورد، تازگی، فلیپ، پیوت پول‌بکی و هم‌پوشانی چند تایم.
   - بیس، فشردگی، پکیج شکست و ناحیه‌های FTR، ETR و CTR، و میزان مصرف گام روزانه هم محاسبه می‌شوند.
3. **موتور قواعد** (`lib/rules.js`) دو ستاپ اصلی را مکانیکی بررسی می‌کند:
   - **برگشت از زون**، با تریگر بسته‌شده‌ی ۱ ساعته.
   - **پکیج شکست**، با ورود در فاصله‌ی یک ATR تریگر از لبه‌ی سطح.

   حد ضرر هیچ‌وقت از ATR تایم تریگر بزرگ‌تر نیست.
4. **هوش مصنوعی** (`lib/ai.js`)
   - Claude این ورودی‌ها را می‌گیرد:
     - خوانش بازار
     - پیشنهاد موتور قواعد
     - متن **قواعد دوره** (`knowledge/rulebook.md`)
     - **آموزش‌هایی که خودتان بارگذاری می‌کنید**
   - بر اساس چک‌لیست دوره تصمیم می‌گیرد و خروجی را به شکل JSON ساختاریافته می‌دهد.
   - سرور هندسه‌ی سیگنال را دوباره بررسی می‌کند: سمت درست حد ضرر، تارگت‌های معتبر و R:R.
   - قواعد دوره و آموزش‌ها با prompt caching کش می‌شوند. به همین خاطر هزینه‌ی تحلیل‌های بعدی کمتر است.

**رفتار بدون کلید API:** برنامه فقط با موتور قواعد کار می‌کند.

**رفتار وقتی درخواست تحلیل رد می‌شود:** قابلیت fallback سمت سرور روشن است. اگر مدل درخواستی را بنا بر سیاست‌هایش رد کند، همان درخواست روی مدل جایگزینِ پیشنهادی Anthropic اجرا می‌شود. برای خاموش‌کردنش `AI_FALLBACKS=off` را تنظیم کنید.

## راه‌اندازی

پیش‌نیاز: Node.js نسخه‌ی ۲۲٫۹ یا بالاتر.

```bash
cd forex-signals
npm install
cp .env.example .env      # ANTHROPIC_API_KEY و APP_PASSWORD را پر کنید
npm start                 # http://localhost:3000
```

- اگر `APP_PASSWORD` را خالی بگذارید، رمز تصادفی ساخته و در کنسول چاپ می‌شود.
- برای امتحان بدون اینترنت یا بدون دسترسی به TradingView، دستور `npm run demo` را بزنید. قیمت‌ها شبیه‌سازی‌شده‌اند و همه‌جا برچسب «نمایشی» دارند.

## اجرای خودکار: هر وقت سرور یا TradingView شما روشن است

سه راه دارد. هر کدام را بخواهید، جدا یا با هم، استفاده کنید.

### ۱. روی سرور خودتان (همیشه‌روشن، پیشنهادی)

وقتی برنامه روی سرور است، **تحلیل خودکار هوشمند** به‌طور پیش‌فرض روشن است:

- هر بار که یک کندل ۱ ساعته بسته می‌شود، برنامه سه نماد را می‌خواند.
- فقط اگر قیمت روی یک زون باشد یا شکستی در جریان باشد، هوش مصنوعی را صدا می‌زند و سیگنال می‌دهد. طبق دوره، ورود فقط همین لحظه‌هاست.
- وقتی بازار بسته است، کاری نمی‌کند.
- سیگنال‌ها در صفحه‌ی برنامه و تاریخچه ثبت می‌شوند. اگر تلگرام را تنظیم کنید، به تلگرام شما هم فرستاده می‌شوند.

**با Docker** (ساده‌ترین راه):

```bash
cd forex-signals
cp .env.example .env        # ANTHROPIC_API_KEY، APP_PASSWORD و بقیه را پر کنید
docker compose up -d        # بعد از هر ری‌استارت سرور، خودش دوباره بالا می‌آید
```

**بدون Docker** (Ubuntu/Debian): این دستور برنامه را به‌عنوان سرویس systemd نصب می‌کند. با روشن شدن سرور اجرا می‌شود و اگر متوقف شود، دوباره اجرا می‌شود.

```bash
bash deploy/install-linux.sh    # بار اول فایل .env را می‌سازد؛ پُرش کنید و دوباره اجرا کنید
sudo journalctl -u forex-signals -f   # لاگ زنده
```

### ۲. روی کامپیوتر ویندوزی خودتان

1. Node.js نسخه‌ی ۲۲ را از nodejs.org نصب کنید.
2. روی `start-windows.bat` دوبار کلیک کنید.
   - بار اول فایل `.env` را باز می‌کند تا کلید و رمز را وارد کنید.
   - بعد برنامه اجرا می‌شود و مرورگر روی `http://localhost:3000` باز می‌شود.
3. اگر می‌خواهید با هر بار روشن‌کردن ویندوز خودش اجرا شود، `autostart-windows.bat` را یک بار اجرا کنید. برای برداشتن این حالت: `autostart-windows.bat remove`.

از داخل ایران، برای رسیدن به API شرکت Anthropic و TradingView به VPN نیاز دارید. سرور خارج از ایران بی‌دردسرتر است.

### ۳. داخل TradingView خودتان (اندیکاتور + هشدار)

فایل `tradingview/khakestar-signals.pine` یک اندیکاتور Pine Script است. همان قواعد دوره را روی نمودارهای خود شما در TradingView اجرا می‌کند:

- پیوت‌ها و زون‌های دوره را پیدا و رسم می‌کند.
- درجه‌ی هر زون را مشخص می‌کند: ۱ساعته، ۴ساعته یا روزانه.
- وقتی تریگر بسته‌شده روی زون ۴ساعته یا بالاتر شکل بگیرد، BUY یا SELL را همراه حد ضرر و تارگت‌ها نشان می‌دهد.
- هشدارهای TradingView روی سرورهای خود TradingView اجرا می‌شوند. پس بعد از ساختن هشدار، حتی وقتی مرورگرتان بسته است هم کار می‌کنند.

**نصب اندیکاتور:**

1. در TradingView، **Pine Editor** را باز کنید. محتوای فایل `khakestar-signals.pine` را جای کد پیش‌فرض بگذارید، **Save** و سپس **Add to chart** را بزنید.
2. آن را روی نمودار **۱ ساعته**ی `OANDA:EURUSD`، `OANDA:XAUUSD` و `OANDA:GBPJPY` اضافه کنید. برای طلا و پوند/ین نمودار جدا باز کنید.
3. برای هر نمودار، هشدار بسازید: **Create Alert**، شرط را `KPA` و **Any alert() function call** بگذارید.
   - فقط برای اعلان خود TradingView (اپ موبایل یا ایمیل): همین کافی است.
   - برای اینکه هر هشدار، تحلیل کامل هوش مصنوعی را روی سرورتان راه بیندازد:
     1. `WEBHOOK_SECRET` را در `.env` سرور بگذارید.
     2. همان مقدار را در تنظیمات اندیکاتور، در فیلد **Webhook secret**، وارد کنید.
     3. در هشدار، **Webhook URL** را `https://دامنه‌ی-شما/api/webhook/tradingview` بگذارید.

   Webhook در TradingView به اشتراک پولی و فعال بودن ورود دومرحله‌ای (2FA) نیاز دارد. فقط به پورت‌های ۸۰ و ۴۴۳ هم فرستاده می‌شود. پس سرور دامنه و HTTPS لازم دارد: `DOMAIN` را در `.env` بگذارید و این دستور را بزنید:

   ```bash
   docker compose --profile https up -d
   ```

   Caddy گواهی HTTPS را خودش می‌گیرد.

### ارسال سیگنال به تلگرام

1. در تلگرام به **@BotFather** پیام بدهید، دستور `/newbot` را بزنید و توکن ربات را در `TELEGRAM_BOT_TOKEN` بگذارید.
2. به ربات خودتان یک پیام بدهید. بعد آدرس `https://api.telegram.org/bot<TOKEN>/getUpdates` را باز کنید و عدد `chat.id` را در `TELEGRAM_CHAT_ID` بگذارید.
3. برنامه را دوباره اجرا کنید.

با تنظیمات پیش‌فرض (`TELEGRAM_NOTIFY=actionable`)، سیگنال‌های خرید و فروشِ تحلیل‌های خودکار و هشدارهای TradingView به تلگرامتان می‌آیند: ورود، حد ضرر، تارگت‌ها و خلاصه.

### نکات مهم برای سرور

- **سرور باید خارج از ایران باشد.** هم API شرکت Anthropic و هم TradingView دسترسی از ایران را محدود کرده‌اند. یک VPS در اروپا کافی است.
- اگر برنامه را روی اینترنت باز می‌کنید، از HTTPS استفاده کنید (`--profile https` بالا). بدون HTTPS، رمز ورود رمزنگاری نمی‌شود.
- داده‌ها در پوشه‌ی `data/` ذخیره می‌شوند؛ در Docker، در volume به نام `fx-data`:
  - سیگنال‌ها
  - آموزش‌ها
  - قواعد ویرایش‌شده
  - رمز ساخته‌شده

## استفاده

- **داشبورد**
  - قیمت زنده‌ی سه نماد.
  - آخرین سیگنال، شامل ورود، حد ضرر، تارگت‌ها، R:R، کیفیت ستاپ و چک‌لیست دوره.
  - دکمه‌ی **«تحلیل تازه»** که Claude را صدا می‌زند.
  - نمودار سطوح دوره: کندل‌ها همراه زون‌های حمایت و مقاومت و خطوط سیگنال.
  - نمودار خود TradingView.
  - جدول‌های «خوانش بازار» که گام هر تایم، زون‌های نزدیک و امتیاز هر زون را نشان می‌دهند.
- **آموزش‌ها و قواعد**
  - PDF، تصویر یا متن آموزشی را اضافه کنید. آموزش‌های فعال همراه هر تحلیل به هوش مصنوعی فرستاده می‌شوند و بر قواعد پیش‌فرض مقدم‌اند.
  - متن قواعد را هم می‌توانید ویرایش کنید.
  - هرچه آموزش‌های فعال بزرگ‌تر باشند، هر تحلیل گران‌تر است. سقف پیش‌فرض ۲۰ مگابایت فایل و ۳۰۰ هزار نویسه متن است.
  - متن کامل دوره خیلی بلند است. خلاصه‌ی آن از قبل در `knowledge/rulebook.md` هست. بهتر است یادداشت‌ها یا قواعد شخصی خودتان را اضافه کنید.
- **تاریخچه**: همه‌ی سیگنال‌های ثبت‌شده.

**هزینه‌ی تحلیل خودکار:** هر اجرای هوش مصنوعی یک فراخوانی پولی API است. حالت هوشمند فقط وقتی قیمت روی زون است Claude را صدا می‌زند، و حداکثر یک بار در هر کندل ۱ ساعته برای هر نماد.

## تنظیمات

همه‌ی تنظیمات در [`.env.example`](.env.example) توضیح داده شده‌اند. مهم‌ترین‌ها:

| متغیر | کاربرد |
|---|---|
| `ANTHROPIC_API_KEY` | کلید Claude؛ بدون آن فقط موتور قواعد کار می‌کند |
| `APP_USER` / `APP_PASSWORD` | ورود به برنامه |
| `DATA_SOURCE` | `tradingview` یا `demo` |
| `AI_MODEL` / `AI_EFFORT` | پیش‌فرض `claude-opus-5` و `high` |
| `AI_FALLBACKS` | `off` برای خاموش‌کردن fallback |
| `AUTO_ANALYZE` | `smart` (پیش‌فرض)، `interval` یا `off` |
| `AUTO_ANALYZE_MINUTES` | فاصله‌ی تحلیل در حالت `interval` |
| `WEBHOOK_SECRET` | رمز webhook هشدارهای TradingView |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | ارسال سیگنال به تلگرام |
| `DOMAIN` | دامنه برای HTTPS خودکار (`docker compose --profile https`) |
| `TV_SYMBOL_EURUSD` و… | تغییر نماد TradingView (مثلاً `TVC:GOLD`) |

## تست

```bash
npm test
```

تست‌ها این بخش‌ها را پوشش می‌دهند:

- محاسبات دوره: ATR، کلاس کندل، پیوت، زون، ارزش سطح و بیس.
- اعتبارسنجی سیگنال.
- پروتکل TradingView، روی یک سرور WebSocket ساختگی.
- فراخوانی Claude، روی یک سرور ساختگیِ Messages API.
- API کامل سرور، webhook TradingView، تحلیل خودکار هوشمند و پیام تلگرام.

## محدودیت‌ها

- داده‌ی TradingView از مسیر غیررسمی خوانده می‌شود. ممکن است تأخیر داشته باشد، قطع شود یا روزی تغییر کند.
- تشخیص الگوها مکانیکی است. همه‌ی ستاپ‌های دوره را پوشش نمی‌دهد (مثل QM، کن‌کن، سه درایو و هارمونیک‌ها). هوش مصنوعی این موارد را فقط از روی داده‌ی کندل‌ها و متن قواعد می‌سنجد.
- `knowledge/rulebook.md` خلاصه و بازنویسی مفاهیم دوره است و جای خود دوره را نمی‌گیرد.
- اندیکاتور Pine همان قواعد مکانیکی را دارد، ولی پیوت‌ها را روی تایم خود نمودار پیدا می‌کند و درجه‌ی زون را با ATR تایم‌های بالاتر تخمین می‌زند. هوش مصنوعی فقط روی سرور است.
