# قالب قرارداد کلاسیکا

`classica-contract-template.docx` — قالب Word «قرارداد طراحی وب‌سایت، سئو و خدمات هوش مصنوعی» برای مجموعه کلاسیکا؛ جلد + ۱۷ ماده + ۲ پیوست (مشخصات فنی پروژه، صورتجلسه تحویل مراحل).

- راست‌به‌چپ، A4، با رنگ‌های لوگو (زرد `#FAB509` و آبی `#1668A2`).
- فونت **Vazirmatn FD** (ارقام فارسی) داخل فایل جاسازی شده است؛ نصب فونت لازم نیست.
- جاهای خالی با نقطه‌چین و گزینه‌ها با ☐ مشخص شده‌اند؛ پانویس هر صفحه جای پاراف طرفین و شماره صفحه دارد.
- عنوان مواد با سبک Heading 1 است و در Navigation Pane دیده می‌شود.

## ساخت دوباره

```bash
npm install --no-save docx@9 vazirmatn
node contracts/classica/build-contract.cjs
```

متن قرارداد در `build-contract.cjs` است؛ `classica-logo.png` همان لوگوی ارسالی است که خطوط دفتر از پس‌زمینه‌اش حذف شده.
